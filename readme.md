# MaxPayne3.FusionShaders

The complete, unmodified Max Payne 3 shader set in editable XML + HLSL form.

- `7,906` `.fxc.xml` RAGE effect containers
- `142,610` `.hlsl` shader programs
- one XML per container; every `<Shader>` points at
  `File="<container>/<shader>.hlsl"` with `DataType="hlsl"`
- no hashes, assembly or binary shader files

This repository is the reference set, for education purposes only.
